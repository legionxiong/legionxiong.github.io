Quick help

Start with the essentials.

ProxyPAC does not provide a proxy server

Add an HTTP upstream proxy that you are authorized to use. ProxyPAC serves the local PAC file and forwards traffic selected by Allowlist or Global Proxy mode to the proxy you configure.

Enable automatic proxy configuration

Copy the PAC URL from ProxyPAC, open macOS Network Settings, select your active service, turn off Web Proxy (HTTP), Secure Web Proxy (HTTPS), and SOCKS Proxy, then enable Automatic Proxy Configuration and paste the URL.

A domain is using the wrong route

In Allowlist mode, add the hostname—not a full URL—to the allowlist. In Global Proxy mode, remove it from the exclusion list if it should use the proxy. Reconnect the app or browser because existing connections may continue using their previous route.

ProxyPAC Pro is not available

Confirm that the Mac is signed in to the App Store and has network access, then use Restore Purchase. Purchases and entitlement checks are handled by Apple StoreKit.

When contacting support

Include enough context to reproduce the issue.

  • ProxyPAC version and build number from Settings → About.
  • Your macOS version and whether the Mac uses Apple silicon or Intel.
  • The action you took, what you expected, and what happened instead.
  • Whether the issue affects service startup, PAC setup, routing, or ProxyPAC Pro.

Protect your credentials: never send proxy passwords, authentication headers, private browsing data, or traffic contents in a support request.
