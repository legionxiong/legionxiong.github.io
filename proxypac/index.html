Designed for control

The routing you need, without a system-wide tunnel.

ProxyPAC serves a local PAC file and forwards traffic selected by your routing mode through proxies that you provide.

01

Two routing modes

Proxy only allowlisted domains, or use Global Proxy while keeping local networks and your exclusion list direct.

02

Fast proxy switching

Save multiple upstream proxies and make a new selection effective for new connections immediately.

03

Automatic failover

Try saved proxies in order when the current one cannot reach a proxied destination—without falling back to direct.

04

Authenticated proxies

Use optional usernames and passwords, with passwords kept in the macOS Keychain instead of the PAC file.

05

Local domain statistics

View proxied domains and per-domain byte counts in memory. Statistics continue after the main window closes and clear when disabled or when the app quits.

06

Native Mac experience

Use the main app for setup and service control, with a lightweight menu bar companion for status and quick proxy switching.

Three steps

Set it once. Switch when you need.

Add your proxy

Enter an upstream proxy server and port. Authentication is optional.

Choose a routing mode

Build an allowlist, or select Global Proxy and optionally add domains that should remain direct.

Enable automatic proxy configuration

Paste the local PAC URL into macOS Network Settings, then keep ProxyPAC running in the menu bar.

Local-first privacy

Your configuration stays on your Mac.

ProxyPAC has no developer-operated analytics, account system, or traffic server. Local services listen only on 127.0.0.1, and live domain statistics are memory-only.
