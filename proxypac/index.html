Designed for control

The routing you need, without a system-wide tunnel.

ProxyPAC serves a local PAC file and forwards traffic selected by Allowlist or Smart Proxy routing through proxies that you provide.

01

Strict allowlist routing

Only domains you add, including their subdomains, use the system PAC proxy. Unmatched traffic remains direct.

02

Smart Proxy learning

Try unknown public destinations directly, start a proxy probe after an adaptive delay, and remember the proxy only after it successfully carries the request.

03

Fast proxy switching

Save multiple upstream proxies and make a new selection effective for new connections immediately.

04

Authentication and failover

Keep proxy passwords in macOS Keychain and optionally try saved proxies in order without falling back to direct.

05

Rule backups

Export and restore allowlist rules without including proxy credentials, app bookmarks, or traffic statistics.

06

Local domain statistics

View proxied domains and byte counts in memory. Statistics clear when disabled or when the app quits.

Three steps

Set it once. Switch when you need.

Add your proxy

Enter an upstream proxy server and port. Authentication is optional.

Choose a routing mode

Use Allowlist for explicit rules, or Smart Proxy to learn which public destinations need the proxy. Allowlisted domains always use it.

Enable automatic proxy configuration

Paste the local PAC URL into macOS Network Settings, then keep ProxyPAC running.

Local-first privacy

Your configuration stays on your Mac.

ProxyPAC has no developer-operated analytics, account system, or traffic server. Local services listen only on 127.0.0.1, and live domain statistics are memory-only.
